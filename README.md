# Hogar animal

Es una página dedicada a un refugio de perros y gatos ficticia en el que se trabaja con colaboradores para prender a usar git y github

## Tecnologias Utilizadas
 
* **Lenguaje:** HTML, CSS, Javascript
* **Otras herramientas:** Git, Github, Visual Studio Code

Antes de comenzar asegurate de tener instalado

* [Git](https://git-scm.com/)

## Instalacion y ejecucion

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1. **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/ByronDSH/practica2.git](https://github.com/ByronDSH/practica2.git)
    ```
2. **Navegar al directiorio del proyecto**
    ```
    cd tu-repositorio
    ´´´

3. **Instalar dependencias**
    ```
    npm install
    ´´´

4. **Instalar el servidor local**
    ```
    npm start
    ´´´
